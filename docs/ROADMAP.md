# Research Roadmap

[← Project home](../README.md) · [Methods](METHODS.md) · [Evidence](EVIDENCE.md)

## Stage One — executable foundation

- [x] persistent, passive-decay, and reinforced-retention mechanisms
- [x] supervised, idle-retention, and sequential-task protocols
- [x] repeated-seed evidence exports and figures
- [x] CLI, desktop collection dashboard, tests, and CI
- [x] explicit claim/evidence boundary

## Stage Two — capstone-scale replication

- [ ] PyTorch mechanism adapter with matched optimizer controls
- [ ] MNIST and Fashion-MNIST preregistered experiment matrix
- [ ] forgetting-rate and reinforcement-strength ablations
- [ ] confidence intervals, effect sizes, and multiple-comparison policy
- [ ] convergence, representation-drift, and energy/runtime measurements

## Stage Three — graduate-level extension

- [ ] CIFAR-10 and corrupted-distribution evaluation
- [ ] established continual-learning baselines such as EWC and replay
- [ ] task-order and distribution-shift sensitivity
- [ ] externally reproducible container and archived dataset hashes
- [ ] preregistered confirmatory study and publication artifacts
